# Changelog

## 0.1.0-alpha.1 (unreleased)

Initial NeoForge 1.21.1 modular-car foundation: standalone Java simulation and CLI dyno; H1 vehicle entity; guarded control/garage payloads; seven starter slots and 16 installable parts; 140 catalogue/model entries; diagnostics and analytical engine graph; fuel, thermal state, engine condition and persistence; original procedural Blender scenes and synthetic audio.

Verification work fixes optional Blender denoiser failure, an HTML redirect incorrectly stored as a Gradle checksum, Gradle's mismatch with the dependency-free test runner, non-atomic invalid-state restoration and replacement of tags required by dependent parts. Adds local/CI evidence, server/client harnesses, development documentation and explicit feature limitations.

This entry describes unreleased development work. It is not a release publication or completion of the full engine/drivetrain/body specification.
