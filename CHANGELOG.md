# Changelog

## 0.1.0-alpha.1 — development foundation

### Added

- Minecraft 1.21.1 / NeoForge 21.1.249 / Java 21 multi-project Gradle workspace.
- Minecraft-free deterministic engine/vehicle simulation, scalar stat resolution, compatibility checks and weakest-component limits.
- CSV dyno and straight-line acceleration CLI, JUnit groups and a dependency-free assertion harness.
- Server-authoritative reference hatch with ownership, driving controls, persistence, fuel, heat and aggregate wear.
- Codec-loaded part definitions, generic part items, candidate validation and workshop removal.
- Live diagnostics, limited ECU limiter adjustment and a calculated dyno graph.
- Original indexed mesh renderer, hatch/interior/engine geometry, wheel/hood animation and workshop models.
- 119 original runtime meshes and 136 part definitions, of which 18 have installable prototype gameplay.
- Procedural inventory renders and editable Blender/GLB authoring pipeline.
- Dedicated GameTests and an actual client/server screenshot smoke harness.
- Requirements, architecture, formulas, configuration, addon, asset and development documentation.

### Scope notice

This is not the full modular-car specification. Detailed suspension, multi-seat entities, independent part health, full ECU maps, measured roller dyno, body swaps/paint/liveries, audio and complete survival progression remain roadmap work. Model-study items are deliberately not installable. See the tested revision's report before using an artifact.
