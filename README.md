# AutoPropulsion Age

A modular vehicle simulation mod targeting **Minecraft 1.21.1**, **NeoForge 21.1.x**, and **Java 21**.

The repository is being bootstrapped from the supplied modular-car requirements. Implementation, documentation, original procedural assets, and a test report will be proposed on a feature branch before merge.

This is a pre-release development project, not a finished mod. No affiliation with Mojang or Microsoft.
