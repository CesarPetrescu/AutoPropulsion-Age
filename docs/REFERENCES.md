# Technical references

The owner's supplied *Modular Car Mod — Requirements, Architecture & Handoff Plan* (2026-09-07) is the product-design baseline. docs/REQUIREMENTS.md summarizes it and records implementation deviations; it is not a statement that its entire feature list is complete.

Toolchain pins were checked against the official NeoForge 1.21.1 ModDevGradle MDK. API integration uses the versioned official NeoForge documentation, with actual compilation and dedicated-server execution as verification rather than assuming examples match every patch release.

- Official MDK: https://github.com/NeoForgeMDKs/MDK-1.21.1-ModDevGradle
- NeoForge 1.21.1 getting started: https://docs.neoforged.net/docs/1.21.1/gettingstarted/
- Payloads: https://docs.neoforged.net/docs/1.21.1/networking/payload/
- Menus: https://docs.neoforged.net/docs/1.21.1/gui/menus/
- GameTests: https://docs.neoforged.net/docs/1.21.1/misc/gametest/
- Blender command-line arguments: https://docs.blender.org/manual/en/4.0/advanced/command_line/arguments.html

The engine curves and geometry are original prototype calibrations, not measurements copied from a manufacturer. Numerical results in this repository are generated by the included tests/tools. No external source establishes the unfinished systems' performance.
