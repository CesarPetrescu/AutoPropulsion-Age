### Why the heading could remain wrong

`ClientPacketListener.handleMoveEntity` preserves the unmodified half of a partial movement packet by reading `Entity.lerpTarget*`. The car interpolated its own position and rotation but inherited getters that returned the **current intermediate pose**. A position-only packet arriving after the first tick of a 0°→90° turn therefore replaced the target with 30°. Rotation-only packets could similarly discard the remaining positional move.

The car now returns pending authoritative targets while interpolation is active, and its current pose after interpolation completes. This preserves vanilla's three-tick interpolation and shortest-arc heading behavior. Steering force, the left-turn assertion and drivetrain tuning are unchanged.

Three deterministic native cases dispatch actual teleport/partial-movement packets through Minecraft's client packet listener: position preserves pending yaw/pitch, rotation preserves pending XYZ, and settled getters follow the current pose. The isolated client probe is removed immediately after the assertions.

Eight live reset cases use headings 90°, -90°, 179°, -179°, 540°, -540°, 37° and 0°. Each requires five fresh server-tick samples with matching position, stopped speed and heading before continuing. The angular synchronization tolerance reflects vanilla's 360/256-degree packet quantization; it does not widen the original steering test. FWD and AWD also require independent convergence after their preceding driving layouts.

### Graphics paths

`runClientGraphics` covers `startup-fabulous`, `menu-fast`, `menu-fancy`, `menu-fabulous` and `menu-fast-again`. The menu test clicks the real `VideoSettingsScreen` widget, including native warning acceptance when presented. It does not call `graphicsMode().set(...)` in a loaded world or manually rebuild the renderer to make the test pass. Each case verifies the active option, transparency target presence and size, completed world rendering and a screenshot of the car.

The first local menu fixture attempted its click before the options list's first layout frame. Waiting one client tick passed locally but failed on the final CI menu transition because a slow renderer can process several ticks before its next frame. The fixture now waits for two actual rendered frames of the current screen and dispatches both mouse press and release. These were fixture errors, not production graphics defects; the release gate rejected both failures.

## Reproduction and evidence

On Windows with Java 21 and Python available:

```powershell
.\gradlew.bat --no-daemon --max-workers=2 -PwithGameTests runClientHandling *> build/ci/handling.log
if ($LASTEXITCODE -ne 0) { throw 'Native handling launch failed' }
python tools/ci/checks.py handling --log build/ci/handling.log --report build/ci/handling.json
.\gradlew.bat --no-daemon --max-workers=2 -PwithGameTests runClientGraphics *> build/ci/graphics.log
if ($LASTEXITCODE -ne 0) { throw 'Native graphics launch failed' }
python tools/ci/checks.py graphics --log build/ci/graphics.log --report build/ci/graphics.json
python -m unittest discover -s tools/ci/tests -v
```

Create `build/ci` first. Run each gate immediately after its native task: the clients share `run/alpha-smoke-result.txt`. The independent battery/energy reproduction remains in the original report. Background native tasks hide their windows and do not take desktop input; the process-local socket workaround for this Windows machine is documented in [DEVELOPMENT.md](../../DEVELOPMENT.md).

Both new native regressions are release requirements. CI rejects missing reset cases, absent partial-packet checks, missing graphics modes, fewer than 45 world frames, or explicit failures even when Gradle exits successfully. The immutable release's `test-evidence.zip` contains fresh reports, logs and screenshots for its exact commit; this document is not an input to any success gate.

These tests do not establish WAN behavior, arbitrary GPU/driver compatibility, other modpacks, subjective audio quality or long-duration populated-world stability.
